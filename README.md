# WinDRV-MinEXIN-Tool
Windowsドライバ 最小構成 エクスポートとインポート（CPU汎用）  
Minimal Windows Driver Export / Import tool for generic CPU environments.

> [!CAUTION]
> ARM系システム（Windows on ARM）では動作未確認です。

WindowsのOSクリーンインストールや再セットアップの前後において、PCで現在稼働しているサードパーティ製デバイスドライバを「最小構成」または「全構成」で安全にバックアップ（エクスポート）し、新しい環境へ正確に復元（インポート）するためのツールです。

単一のバッチラッパー（`.cmd`）形式で提供されていますが、内部では Windows 標準の PowerShell スクリプトおよび公式ドライバ管理コマンド `pnputil.exe` を直接呼び出して安全・確実に処理を実行します。サードパーティ製の外部ツールや追加ランタイムのインストールは一切不要で、Windows 標準の環境のみで動作します。

マニフェストファイル（driver-backup.json）を生成して突合させることも特徴的な機能です。

---

## 主な特徴

- **スマートな「最小構成」エクスポート**  
  現在接続・稼働中の物理デバイスに必要なドライバ、およびブートに必須なドライバ（`BootCritical`）や関連コンポーネント（Extension, SoftwareComponent, AudioProcessingObject）のみを自動選別して保存。使われていない旧バージョンや不要なドライバを除外し、バックアップ容量と復元時間を大幅に削減します。
- **ディスプレイドライバのオンライン取得切り替え（容量節約）**  
  容量の大部分（数百MB〜数GB）を占めるディスプレイドライバをローカルバックアップから除外可能。復元時にネットワーク経由でMicrosoft Update カタログから同一・適合バージョンのWHQLドライバを自動ダウンロード＆適用できます。
- **改ざん・破損防止の完全性検証**  
  エクスポート時に全ファイルのサイズ・SHA-256ハッシュを記録したマニフェスト（`driver-backup.json`）を生成。復元前にハッシュ照合およびAuthenticodeデジタル署名（CAT）の検証を自動で行い、安全性を担保します。
- **自動UAC管理者昇格**  
  管理者権限が必要な処理のため、通常実行しても自動的に管理者権限の昇格ダイアログ（UAC）が表示されます。
- **デバイス診断機能**  
  必須5カテゴリ（オーディオ / ビデオ / 有線LAN / 無線LAN / Bluetooth）の適用状態や、未適用・エラー（Problem 28 / Null Driverなど）となっているデバイスをワンクリックで診断できます。

## 動作要件

| 項目 | 要件 |
| :--- | :--- |
| **対応OS** | Windows 10 / Windows 11（x64 / x86） |
| **実行基盤** | Windows PowerShell 5.1 以降（OS標準搭載） |
| **権限** | 管理者権限（実行時に自動昇格ダイアログが表示されます） |

## 使い方

### 全体の流れ
```mermaid
flowchart LR
    A[OS再インストール前] --> B[エクスポート実行]
    B --> C[USB等へバックアップ退避]
    C --> D[OSクリーンインストール]
    D --> E[復元実行]
    E --> F[ドライバ復元完了]
```

---

### 事前準備
1. [リポジトリの最新版](https://github.com/CTD-Networks-CO-LTD/WinDRV-MinEXIN-Tool) から `Windowsドライバ_最小構成_エクスポートとインポート_CPU汎用.cmd` をダウンロードします。
2. 作業用フォルダやUSBメモリ等に配置します。

---

### Step 1: エクスポート（OS再インストール前）

1. `Windowsドライバ_最小構成_エクスポートとインポート_CPU汎用.cmd` をダブルクリックして実行します。  
   ※UAC（ユーザーアカウント制御）の確認画面が表示されたら、「**はい**」を選択してください。
2. メインメニューが表示されます。

   ```text
   メインメニュー
     エクスポート（OS再インストール前）
       [1] 最小構成で保存   必須ドライバ（オーディオ・ビデオ(選択式)・LAN等）の保存と未使用・旧版を除外
       [2] 全て保存         未使用・旧版を含む全サードパーティINF

     インポート（OS再インストール後）
       [3] 保存フォルダから復元

     診断・確認
       [4] システム・デバイスドライバ適用状態の診断（読み取り専用）

       [0] 終了（Qでも可）
   ```

3. **`1`**（最小構成で保存・推奨）または **`2`**（全ドライバ保存）を入力して Enter を押します。
   - **`1`（最小構成）**: 現在接続されているデバイスで実際に使用中のドライバと必須コンポーネントのみを抽出します。通常はこちらを推奨します。
   - **`2`（全ドライバ）**: DriverStore内に登録されているすべてのサードパーティ製ドライバ（`oem*.inf`）を保存します。
4. **保存フォルダ名の入力**:  
   保存先フォルダ名の入力を求められます。既定値は `driver`（`.cmd` と同じ階層）です。変更しない場合はそのまま Enter を押します。
5. **ディスプレイドライバのオンライン取得選択**（※最小構成の場合のみ）:  
   物理ディスプレイドライバが検出された場合、以下の確認が表示されます。

   ```text
   ディスプレイドライバをローカル保存せず、復元時にインターネット（MSカタログ等）から自動取得しますか？ [Y/N]
   ```
   - **`Y`（既定・Enter）**: ディスプレイドライバをローカル保存から除外し、メタデータのみを記録します。バックアップサイズを大幅に削減できます（復元時にインターネット接続が必要）。
   - **`N`**: ディスプレイドライバのパッケージ本体もローカルフォルダに保存します（オフライン環境で復元したい場合に適しています）。
6. **処理の完了**:  
   ドライバの抽出、依存関係（`CopyINF`）の解析、出力ファイルのSHA-256検証が順次実行されます。  
   完了メッセージが表示されたら Enter キーを押してメニューに戻ります。

---

### Step 2: バックアップの退避

エクスポートが完了すると、`.cmd` と同じフォルダに以下のファイル・フォルダが作成されます。

- **`driver`** フォルダ（または指定した名前のフォルダ）: ドライバ一式、マニフェスト（`driver-backup.json`）、`_エクスポート内訳レポート.txt`
- `Windowsドライバ_最小構成_エクスポートとインポート_CPU汎用.cmd`

これらを**USBメモリや外付けストレージ**などの外部媒体へコピーしてください。  
※OSのクリーンインストールで内蔵ストレージが初期化されるため、必ず外部ドライブへ退避してください。

---

### Step 3: インポート・復元（OS再インストール後）

1. 新しいOSのセットアップ完了後、退避したフォルダおよび `.cmd` ファイルをデスクトップなどの作業場所に配置（またはUSBメモリから直接開く）します。
2. `Windowsドライバ_最小構成_エクスポートとインポート_CPU汎用.cmd` をダブルクリック（または右クリックして「管理者として実行」）します。
3. メニューから **`3`（保存フォルダから復元）** を選択します。
4. **復元対象フォルダの選択**:  
   同一フォルダ内にあるバックアップ候補が一覧表示されます。復元したいフォルダの番号を入力するか、既定の `driver` であればそのまま Enter を押します（別の場所にある場合は `M` で絶対パス入力も可能）。
5. **検証と確認**:  
   - マニフェスト（`driver-backup.json`）によるファイルの完全性照合（存在・サイズ・SHA-256）
   - 各ドライバパッケージのデジタル署名（CAT署名）  
   が自動検証されます。  
   「このフォルダから復元しますか？ [Y/N]」で **`Y`**（またはEnter）を入力します。
6. **復元処理の実行**:
   - **フェーズ1（ローカル復元）**:  
     `pnputil` により検証済みドライバを順次システムに追加・適用します。必要に応じて子デバイスの再スキャンや未バインドデバイスへの強制バインド救済が行われます。
   - **フェーズ2（オンライン復元・設定時のみ）**:  
     ディスプレイドライバをオンライン取得にしていた場合、ネットワーク経由でMicrosoft Update カタログから適合するドライバを自動ダウンロード・展開・署名検証・インストールします。
7. **完了と再起動**:  
   事後診断が自動実行され、各デバイスへの適用状態が表示されます。  
   処理完了後、ドライバを正しく有効化するために**Windowsを手動で再起動**してください。

---

### （オプション）デバイスドライバ適用状態の診断

メニューから **`4`（システム・デバイスドライバ適用状態の診断）** を選択すると、システムに変更を加えることなく（読み取り専用）、以下の状態を確認できます。

- **必須5カテゴリの適用状況**:
  - Audio（サウンドデバイス）
  - Video（ディスプレイアダプター）
  - 有線LAN（Ethernet）
  - 無線LAN（Wi-Fi）
  - Bluetooth
- **未適用・異常デバイスの検出**:  
  PnPの問題コード（Problem 28: ドライバ未インストールなど）が発生しているデバイスや、ドライバがバインドされていないデバイスの一覧と詳細。

OS再インストール前の事前確認や、復元後の最終チェックとしてご活用ください。

## メニュー構成リファレンス

| キー | 項目名 | 内容 |
| :---: | :--- | :--- |
| `1` | **最小構成で保存** | 接続中デバイス・ブート必須ドライバに絞り込んでエクスポート。ディスプレイドライバのオンライン取得切り替えが可能。 |
| `2` | **全て保存** | DriverStore 内の全サードパーティ製ドライバ（`oem*.inf`）をエクスポート。 |
| `3` | **保存フォルダから復元** | バックアップフォルダを選択し、完全性・署名検証後にローカル復元およびオンライン取得を実施。 |
| `4` | **適用状態の診断** | 主要5カテゴリおよび未適用/異常デバイスの稼働状態を診断（読み取り専用）。 |
| `0` / `Q` | **終了** | スクリプトを終了します。 |

## バックアップ成果物の構成

エクスポートを実行すると、指定フォルダ（既定: `driver`）内に以下のファイル群が生成されます。

```text
driver/
├── driver-backup.json              # バックアップ全体の完全性マニフェスト（ファイルハッシュ、デバイス情報等）
├── _エクスポート内訳レポート.txt     # 人間が確認できるエクスポート対象・除外理由・容量内訳の一覧
├── <ドライバパッケージフォルダ>/    # 各ドライバのパッケージ実体（INF, CAT, SYS, DLL等）
└── ...
```

復元実行時には、同一ディレクトリに実行ログ `driver-import-YYYYMMDD-HHMMSS-fff.log` が出力され、トラブル時の原因調査に使用できます。

## 注意事項・トラブルシューティング

- **OS初期化前の確認**  
  エクスポート処理がエラーなく完了し、保存先フォルダにファイル一式と `driver-backup.json` が生成されていることを必ず確認してから、古いOSの消去や初期化を行ってください。
- **再起動の推奨**  
  復元処理完了後、画面上に「要再起動」と表示された場合や、新しいグラフィックス・オーディオドライバを反映させるため、必ずPCを手動で再起動してください。
- **インターネット接続**  
  最小構成エクスポートでディスプレイドライバのオンライン取得を選択した場合、復元フェーズでMicrosoft Update カタログと通信するためインターネット接続が必要です（有線LANまたはWi-Fiドライバが復元された後に通信が行われます）。
- **パスの制約**  
  セキュリティ保護のため、シンボリックリンクやジャンクション（再解析ポイント）が含まれるフォルダパスでの実行や保存はエラーとなります。通常のローカルドライブやUSBメモリの直下等で実行してください。
- **ARM環境について**  
  ARM64 アーキテクチャの Windows では動作確認が行われておりません。x64 / x86 の汎用CPU環境を対象としています。
